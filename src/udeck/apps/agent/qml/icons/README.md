# Agent 图标

操作图标来自 [Bootstrap Icons 1.13.2](https://github.com/twbs/icons/releases/tag/v1.13.2)，保留原始路径，使用 uDeck 界面配色。

Codex、Claude、OpenCode 和 Pi 的标志来自 [LobeHub Icons 静态 SVG 1.106.0](https://www.npmjs.com/package/@lobehub/icons-static-svg/v/1.106.0)。品牌标志用于识别对应 Agent，品牌权利由各自持有者保留。保持原始轮廓，统一掌机上的图标尺寸和色彩表现。

`manifest.json` 记录分发来源、原图和随包图标的 SHA-256。两套资源的 MIT 许可文本与图标一同分发。
