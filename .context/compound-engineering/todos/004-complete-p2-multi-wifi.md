# 多无线网卡管理

## Problem Statement

uConsole 同时使用内置和 USB 无线网卡，目前只枚举、操作第一张网卡。

## Findings

- NetworkManager 后端遇到第一张无线网卡即退出枚举。
- 扫描和连接依赖全局单个设备，菜单切换会丢失父级和焦点。
- 现有输入、终端与会话功能已在基线提交中，独立工作树保留它们。

## Proposed Solutions

采用已批准的网卡列表 → 单网卡网络列表，所有操作绑定设备；路由由系统管理。

## Recommended Action

先验证后端枚举与操作隔离，再实现分层菜单、热插拔和状态摘要，最后执行全量测试、截图与可用的实机检查。

## Acceptance Criteria

- [x] 全部网卡枚举、总线识别、独立扫描/连接/断开与配置防抢占。
- [x] 分层导航、焦点保留、拔插恢复、局部错误及双网卡 Mock。
- [x] 全量测试、Ruff、QML 截图及实机边界记录。
