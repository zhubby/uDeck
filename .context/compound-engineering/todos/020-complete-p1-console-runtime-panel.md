# Console 应用运行面板

## Problem Statement

Running 的双行大卡片无法展示资源与存活时间。
用户确认改为每应用一行的 Console 紧凑表格。

## Findings

- Wayland 窗口协议不提供 PID。
- 六个内置应用有会话专属 D-Bus 服务。
- 实机支持 `/proc`、pidfd 与进程树读取。
- 模拟器正常关闭窗口只暂停游戏。
- 原工作区差异已由远端 main 的 6f5034e 交付。

## Proposed Solutions

采用独立运行服务与增量 QML 模型。
以 D-Bus 服务确定身份，以 `/proc` 采样资源。
保留现有全局控制面板与兼容入口。

## Recommended Action

按用户已确认的计划执行。
应用、状态、CPU、内存、存活时间、退出各占一列。
正常退出与确认后的强制终止分离。
模拟器正常退出仅写回原生存档，不新增即时存档。

## Acceptance Criteria

- [x] 48px 单行表格与双主题、中英文布局。
- [x] 有界异步采样、进程树统计、稳定选择与滚动。
- [x] 原生退出请求、模拟器写回与终端确认。
- [x] pidfd 身份校验与隔离进程终止回归。
- [x] 离屏回归、Ruff 与文档同步。
- [x] 实机 Wayland 流程、截图与自动化证据。
- [x] 点击或确认键打开实时详情，保留独立退出与终止确认。
