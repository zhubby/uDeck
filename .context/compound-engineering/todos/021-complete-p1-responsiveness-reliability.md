# 响应速度与会话可靠性

## Problem Statement

用户确认逐项推进返回延迟、首帧、恢复、CI 和包身份。
正式桌面保持运行；故障与升级测试使用隔离环境。

## Acceptance Criteria

- [x] 返回路径有界计时；授权查询不阻塞界面。

- [x] 会话使用滚动崩溃预算；正常退出和 TERM 不重启。
- [x] push/PR 执行 lint、版本和隔离测试；deb 仅在 Release 构建。

- [x] 文档、隔离调度器、完整测试和代码审查完成。
