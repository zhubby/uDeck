# Browser 实机测试与修复（2026-11-11）

本次在 uConsole `zhubby@192.168.11.59` 的正式 Browser 窗口及 Qt 6.8.2 网页引擎上测试，修复三个操作问题，未修改桌面会话、Reader 或模拟器的实现。

| 问题 | 原因与修复 | 验证 |
| --- | --- | --- |
| 缩放后，方向键选中的链接点不中，输入框无法正确接收文字 | JavaScript 返回 CSS 坐标，原实现直接用作窗口坐标。点击前按 `WebEngineView.zoomFactor` 转换，再映射到窗口。 | 80%、100%、125%、150%、200% 五档，真实 HTTP 页面链接跳转与 `abxy` 表单提交均通过。修复前非 100% 场景可复现失败。 |
| 阅读、输入或指针模式中新建标签，仍沿用旧模式；关闭阅读标签后，旧文章覆盖替换标签 | 新建、关闭当前标签和切换标签时，恢复网页导航并清除旧阅读内容。关闭后台标签保留当前阅读模式。 | 控制器回归、真实 WebEngine 阅读提取与 Ctrl+T、正式窗口经 Wayland 虚拟键盘操作均通过。正式窗口修复前记录为 `reading` 和旧文本，修复后为 `navigation` 和空文本。 |
| 新标签页的书签入口无法通过方向键选中 | 增加起始页的选择状态，上下键选择地址或书签，确认键执行对应操作；两按钮的边框显示当前选择。 | 控制器及实际 QML 按键回归通过，正式窗口上下键、确认、取消均通过。 |

## 验证结果

- 本地浏览器相关回归 **33 项通过**；补充实际阅读提取与 Ctrl+T 后，交互回归 **12 项通过**。Ruff 与差异空白检查通过。
- 实机安装后的五档缩放交互回归全部通过。实机原生流程同时覆盖链接导航、输入、标签历史、阅读提取、虚拟指针、书签／历史、最后标签替换、主题切换、下载取消／确认／重名保护，共 **12 项流程检查通过**，QML 错误为空。
- 正式窗口通过合成器虚拟键盘执行地址输入、方向键、确认、Ctrl+T 与菜单；这是设备自动化输入验证，不代表人工逐键验收。
- 正式窗口真实 HTTPS 访问 `https://example.org/` 成功；本机拒绝连接的地址能显示错误，通过 Ctrl+L 重新输入地址后恢复访问，刷新通过。
- Python 官网已真实渲染；部分资源持续加载，因此另外验证停止加载并保留可见页面。截图不作为该站全部资源加载完成的证明。
- 额外运行其他原生应用回归时，Video 曾在读取尚未就绪的 `videoSink` 时失败；原 Browser 源码与当前源码各自复测均通过。本次未修改 Video，也不将该额外检查计入浏览器验收。
