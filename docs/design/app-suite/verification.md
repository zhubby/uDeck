# 设计验证与代码审查

## 自动化范围

`verify.py` 使用本地临时 HTTP 服务和独立 Chromium 会话，测试结束后关闭自己的浏览器与服务。无需在生产项目增加 npm 或 Python 运行依赖；需要评审机已安装 `agent-browser`。

```sh
rtk proxy python3 docs/design/app-suite/verify.py
rtk proxy node --check docs/design/app-suite/prototype/app.js
rtk proxy node --check docs/design/app-suite/prototype/data.js
rtk proxy .venv/bin/ruff check src tests tools docs/design/app-suite
```

浏览器矩阵覆盖英文/简体中文 × 1280×720 / 960×600 × 五个应用。逐一检查内容库、操作菜单、语言菜单和主要内容页面；每个应用还覆盖空内容、加载、打开失败与来源移除。检查窗口外溢、焦点是否被裁切、焦点是否位于当前弹层、状态与 DOM 焦点是否一致、封面是否加载以及资源是否全部来自本地。

专项流程使用真实键盘事件和页面控件：普通 abxy 输入、切换语言保留草稿、Tab 焦点同步、禁用项跳过、队列重排/删除、播放器与队列逐层返回、视频文件夹筛选、续播、章节边界、隐藏控制栏保留字幕、地址校验、网页缩放/阅读/文字/指针、标签 ID、书签与历史、阅读跳页/查找/书签/PDF、游戏预检、B 不退出游戏、保存/覆盖/读取确认及存档期间丢失来源。

结果以最终运行的 `artifacts/app-suite/verification/report.json` 为准；完整截图保存在同一目录。此目录被仓库忽略，可通过脚本重新生成。设计总览为本轮截图的缩图拼接，不使用上游项目截图。

最终运行结果：**499 项检查通过，195 张截图**。英文与简体中文、1280×720 和 960×600 的完整矩阵及专项流程均通过；Chromium 未记录未处理的 JavaScript 错误。报告同时保存全部原型源码和 SVG 的 SHA-256，用于核对截图对应的版本。

`node --check` 对 `app.js`、`data.js` 均通过；`ruff check src tests tools docs/design/app-suite` 通过；27 份原创 SVG 的 XML 解析通过。生产源码与依赖未改动，本轮没有把此前的 289 项 Python 测试计入这 499 项设计检查。

## 验收边界

本轮可确认的是设计原型在桌面 Chromium 内的布局、交互、语言、状态与恢复路径。已有 i18n/多网卡的测试和 uConsole 安装记录仍属于那些功能，不算本次媒体应用已运行的证据。

以下在原生接入后逐项验收：

- 实体 ABXY/LR、轨迹球、独立控制器的所有权交接，中文输入法候选与 Wayland/Xwayland。
- 真实音频输出和蓝牙切换，视频硬件解码、音画同步、字幕轨与长时间播放。
- QtWebEngine 的 arm64 包、真实网站、账户/表单/下载/权限/证书与内存。
- 真实 PDF/EPUB/TXT 的排版、搜索完整性、编码、缩放与逻辑位置恢复。
- 每个平台/核心的真实帧率、音频、保存/覆盖/读取、优雅退出与异常中断。
- SD 实际拔插、挂载身份复用、电源中断和失败恢复。

这些待验收项没有被浏览器截图替代。本轮不向设备安装设计原型，不中断现有终端、会话或无线连接。
