# UI 交互音效

## 素材与映射

统一使用 [Kenney Interface Sounds](https://kenney.nl/assets/interface-sounds)
1.0，原始包包含 100 个 OGG，许可为 CC0-1.0。本项目仅选择以下八个声音。

| 交互 | 原始声音 | 时长 |
| --- | --- | ---: |
| 焦点移动、列表选择、滑块细调 | `tick_001.ogg` | 45 ms |
| A / Enter 确认、执行按钮 | `select_001.ogg` | 40 ms |
| 打开菜单、弹层、切换页面 | `open_001.ogg` | 148 ms |
| B / Esc 返回、取消、关闭弹层 | `back_001.ogg` | 61 ms |
| 开关开启 / 关闭 | `toggle_001.ogg` / `toggle_002.ogg` | 136 ms |
| 用户请求的操作实际完成 | `confirmation_003.ogg` | 322 ms |
| 操作失败、功能不可用 | `error_008.ogg` | 139 ms |

原始包 SHA-256 为
`f2193d072726d6758a5f7871b2dcc54dcce0d5c35c6f0a62f92549b327c81232`。
保留原始 `License.txt`，来源和每个文件的原始及转换后 SHA-256 记在
`src/udeck/assets/interface-sounds/manifest.json`。

导入时转换为 48 kHz、单声道、16 位 PCM WAV，并仅作固定增益衰减，
各声音峰值为 -18 至 -13 dBFS。没有改变音调、长度或节奏；运行时无需
FFmpeg 或网络下载。资源随 wheel 和基础 Debian 包离线分发。

## 播放规则

- 启动器、设置、五个原生应用和终端菜单共享语义映射与播放实现。
  第三方应用和真实游戏输入不产生 uDeck 音效。
- 只对实际发生的交互反馈。焦点或滑块已到边界不响；鼠标悬停、文字输入、
  网页按键、终端命令输入、阅读内容滚动和后台状态刷新不响。
- 同一交互优先选择更具体的声音，不叠加确认与打开声。事件优先级为
  错误、成功、开关、返回、打开、确认、导航。
- 导航音间隔至少 90 ms，不打断尚未结束的操作结果音。播放新声音前停止
  旧声音，不建立长按按键的音效队列。
- 成功音只跟随用户发起且实际完成的操作，不把命令接收当成完成。
  文件夹读取不发成功音；Wi-Fi 等待对应网卡、操作身份和已确认的连接状态，
  重复状态刷新不重复播放，取消、移除、服务重启或被其他连接取代时不报成功。
- 失去前台焦点时停止播放并清空待播事件；无默认输出设备、样本未就绪或
  加载失败时静默降级，不阻塞、不弹出递归错误，也不恢复播放过期事件。
- 使用系统默认输出设备，设备列表或默认输出变化时重新绑定。只控制应用
  自身的短音效，不修改系统音量、静音、媒体输出选择或录音配置。
- Offscreen 自动化预览不初始化音效播放，避免截图和测试发声。

## 设置

系统设置和 Y 快捷设置提供同一个「Interface sounds / 交互音效」开关，
默认开启，以低音量反馈；状态存入 `settings.json` 的
`preferences.uiSounds`，只接受布尔值。关闭音效的动作本身不会强制发声。
其他已打开的应用在下次交互前重新读取此开关；保存焦点或语言时不能把
另一进程刚写入的音效偏好覆盖回去。保存失败保留原值并显示本地化提示。

## 验证边界

资源检查覆盖来源校验、原始许可、PCM 规格、时长和低峰值。控制器与播放
测试覆盖单次交互去重、导航限频、无效移动、文本输入、前后台切换、设备
丢失、损坏样本、偏好持久化和真实结果事件。实际 QML 窗口通过键盘事件
检查中英文、经典／黑暗主题、1280×720 和 960×600 下的开关及快捷设置。

自动化信号、解码、播放状态和截图不能证明 uConsole 实体扬声器／耳机的
实际听感、系统静音、蓝牙切换延迟、物理按键或与游戏音频混音的体验；这些
需要目标设备上的独立听音验收。
