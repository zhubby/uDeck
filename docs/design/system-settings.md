# uDeck 时区与键位测试

系统设置和 Y 快捷设置提供相同的「时区」「键位测试」入口。复用经典／黑暗调色板、Saira Semi Condensed／LXGW 字体、现有菜单与 Kenney 按键提示，适配 1280×720 和 960×600。

## 设置项图标与文字

系统设置主列表保留「名称＋当前状态／说明」双行。系统设置内的子菜单、快捷设置以及六个子应用的应用设置使用单行：左侧为图标和名称，右侧为当前状态、值和进入下一层的箭头；长名称或状态各自在本列省略，不换行、不相互覆盖。菜单标题及独立说明仍可换行。应用设置中的布尔项显示实际状态文字与开关，选择菜单在右侧标记当前值；路径在右侧从中间省略，悬停可查看完整内容。开关操作保留菜单及选中行，子菜单返回后更新父行状态。应用的其他操作菜单保留原有详细说明。

Wi-Fi 总开关、热点、蓝牙及发现、自动加入、扬声器／麦克风静音、界面音效在右侧使用 switch 指示器，并显示开关文字。开关绑定实际设备或已保存设置，不预先翻转；请求处理中显示「正在应用…」，失败后保留实际状态。设备、网络等导航入口仅显示状态及箭头，不显示开关。操作继续由现有 A／Enter 和手柄导航触发，不增加独立焦点；断网、热点切换及电源操作沿用现有确认流程。

图标高度等于相邻名称文字块的实际行高：主列表为两行高度，单行子菜单为一行高度。

图标保持正方形和原有比例，与文字块垂直对齐；行内上下留白不计入图标高度。尺寸由实际文字布局决定，随字体、语言和换行自动更新，不使用固定像素尺寸或以字号估算行高。设置行和弹层按内容高度布局，保留既有滚动与键盘导航。

## 时区

按「区域 → 城市」选择，默认定位当前系统时区。城市保留 IANA 名称，区域及操作提示支持中英文。A 应用后菜单保持打开；B 逐层返回，保留区域、城市和设置入口的焦点。外部时区变化更新当前标记，不改变用户正在选择的项目。

后端通过系统 D-Bus `org.freedesktop.timedate1` 的 `Timezone`、`ListTimezones`、`SetTimezone(sb)` 查询和保存。区域与城市由系统实际可用列表生成。保存前再次读取系统状态并核对列表，修改时允许系统认证代理处理权限；只在读回目标时区后显示成功。不写入 `preferences`，不自行维护另一份系统时区，不调整系统时间、NTP 或 RTC。重复选择当前值为无写入操作。

保存期间禁用重复提交并显示进度。服务不可用、认证拒绝、保存失败或无法核验时显示错误与实际当前值，恢复可选状态。订阅属性变更及服务所有者变更，恢复后刷新列表。顶部时钟按明确的系统时区转换当前 UTC 时间，每秒刷新；不依赖 QML JavaScript 的本地时区缓存，也不重建应用页面或终端会话。

## 键位测试

同一屏显示完整键盘、Fn 层输出、方向键、ABXY、L/R、Select／Start 和轨迹球。左侧按字母／数字／符号、修饰键、F1–F12、编辑导航、音量／亮度分组，右侧保留游戏按键示意并增加轨迹球移动、按下和滚轮。按下时高亮并轻微缩小，松开后复原，已测试键位保留勾选标记。同时显示最近按键、来源、当前按住的组合、按下次数与已测试数量。细节遵循[按键图标规范](input-prompts.md#键位测试中的反馈)。

按官方固件键表建立 104 个可检测输出；该数量包含 Fn 层、鼠标移动及滚轮，代表可检测的输出，不是 104 个物理按钮。左右 Shift／Ctrl／Alt 分别显示。Shift 产生的符号继续对应原键帽；例如 `!` 对应 `1`，松开 Shift 后释放仍能清除高亮。Enter、Esc、F1、F10、PageUp、PageDown 高亮各自的键盘键帽；普通 J／K／U／I 或 A／B／X／Y 不冒充游戏按键。固件键盘模式下，游戏按键与字母无法区分，按实际收到的 J／K／U／I、Space／Enter 显示。

Fn（两个实体位置）、键盘背光、锁键与电源分别标为固件／系统处理，不计入可检测输出分母，也不显示为检测失败。Fn 单独按下不发送 USB 键码；通过 F1–F12、PageUp／PageDown／Home／End／Insert／Delete／CapsLock／PrtSc／Pause 和媒体输出检测组合结果。电源键不作为应用内按键测试。

键盘事件在测试弹层内先于 QML 导航处理；原生 Linux 只读观察器补充 uConsole 键盘和 Consumer 接口被桌面提前处理的报告。观察器仅在诊断页位于前台时打开设备，不 grab，不更改快捷键或输入映射，关闭、失焦或被其他弹层打断后立即停止。系统保留的快捷键仍由桌面处理；uDeck 自身的主页／窗口切换／确认／翻页等动作不执行。原生报告与 Qt 事件合并为一次按压：按实际可读接口声明的键位持续使用原生报告，包括两次按压之间，避免完整 Qt 事件批次迟到后重复计数或残留高亮；仅清除已覆盖键位的 Qt 影子状态，不同原生来源仍按住时继续高亮。未覆盖键位及原生接口失联后由 Qt 处理；权限不足明确提示，Qt 可见的键盘测试继续可用。

Gamepad、Select／Start 和内置肩键使用实际输入边沿。方向轴支持同时按下的两个方向。L/R 对应原生鼠标左右键，轨迹球按下对应中键；四向移动和上下滚轮独立标记。轨迹球和滚轮只有相对增量，收到增量时提供 180ms 活动反馈，连续移动延长反馈，不将移动计入按下次数。Select＋轨迹球验证固件滚轮输出。

诊断代码不发送校准、映射或系统设置修改命令；系统处理的音量、亮度快捷键可能仍生效。短按 B／Esc 可测试本键；长按 1.2 秒返回。返回后保留设置或快捷菜单中的位置和已有文字输入。焦点丢失、临时弹层打断、设备断开和事件流失同步时清除对应按住状态并取消退出计时。后台输入不进入测试。

仅缩放图标容器的绘制，不改变布局尺寸。`UDECK_REDUCED_MOTION=1` 关闭缩放过渡。按下状态同时通过边框和文字表达，已测试状态使用勾选；键位图为只读诊断。键帽实例不随状态快照重建，运行中切换语言／主题保留按住状态与已测记录。后台提示复用说明行显示单行摘要，防止长消息挤出小屏弹层；其他菜单保留详细提示。

## 验收边界

自动化覆盖真实 QQuickWindow 的键盘按下／松开、自动重复抑制、组合、普通字母、短按及长按返回，以及设备事件模拟、断开、焦点和弹层打断。截图使用 Mock，不证明实体按键正常。实机可只读核对时区服务、有效列表、无变化请求和安装完整性；主动修改系统时区、图形认证与现场实体按键另外记录，不能用管理员命令或模拟事件替代。
