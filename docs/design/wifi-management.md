# Wi-Fi 加入与已保存网络管理

沿用现有菜单、经典／黑暗主题、Saira Semi Condensed／LXGW 字体和 Kenney 按键图标。入口始终为「设置或 Y 快捷设置 → Wi-Fi → 网卡 → 网络」，保留内置与 USB 网卡的独立状态，由系统继续管理上网路由。

## 层级与焦点

方向键选择，A 打开网络操作菜单，B 每次返回一层。操作后保持网卡和网络菜单，刷新按设备路径、SSID 原始字节与非翻译安全类型、配置 UUID、菜单操作 ID 保留焦点。扫描 AP 对象更换、语言变化和信号排序不作为新的网络身份。

同名多配置先展示配置名称、UUID 和当前配置标记，再进入所选配置的操作菜单。后台连接进度不能替换用户明确选中的配置；配置被外部删除后不自动把管理操作转向另一份同名配置。

## 操作菜单

| 状态 | 操作 |
| --- | --- |
| 未保存 | 加入网络、网络详情 |
| 已保存 | 加入网络、自动连接开关、修改密码（个人加密）、遗忘网络、网络详情 |
| 已连接 | 重新加入、断开连接，以及对应配置的管理操作 |
| 正在加入 | 实际连接阶段、取消加入；禁用重复加入与配置修改 |
| 加入失败 | 系统原因、重试、重新输入密码（存在可修改的个人配置时）、详情 |

开放网络加入前确认并说明风险。替换这张卡的已有连接时，确认说明可能中断经由该卡的 SSH；不主动断开另一张网卡。另一张卡正在使用的单实例配置禁止激活，从扫描列表仍可创建独立配置。

正在准备、配置 Wi-Fi、等待凭据、获取地址和检查连接均依据系统状态显示。请求返回不作为加入成功；90 秒未完成只提示超时并允许继续等待或取消，不主动断开。B 返回只关闭菜单，已提交的加入必须通过「取消加入」取消。取消绑定本次操作身份和实际活动连接，不能取消后来的其他连接；请求返回晚于取消时也只处理原连接。

## 密码

输入默认隐藏，X（键盘 F10）显示或隐藏本次输入。校验错误保留输入并在框上方显示原因。WPA2 校验 8–63 字节或 64 位十六进制 PSK；空值和空字符拒绝。已有密码从不读取或回填到界面。

修改密码只保存所选配置，提示「新密码将在下次加入时使用」，由用户手动选择重新加入。保留其他网络配置字段、凭据和当前连接。输入结束后重新核对设备、配置 UUID、版本与占用；输入期间配置发生外部变更时拒绝覆盖。

## 遗忘与自动连接

遗忘确认默认选中取消，正文说明会删除所选配置及其密码；活动配置先精确断开并等待实际结束，再删除。断开失败不删除；断开后删除失败明确说明「已断开，遗忘失败」。同名其他配置保留。

自动连接开关持久化到所选配置，关闭不会立即断开。保存失败重新读取实际状态。另一张网卡使用同一配置、无法确认占用、只读或无法确认高级兼容约束时，相关修改禁用并说明原因。

## 已保存网络与详情

保存列表独立于扫描，网络不在范围内或全部 Wi-Fi 关闭时仍可进入管理。按接口与 MAC 绑定过滤；高级硬件匹配暂不可确认时保留可见说明并禁用相关操作，激活前再次核对系统状态。

详情使用可滚动菜单展示 SSID、网卡、状态、安全类型、信号、IP、网关、DNS 和所选配置身份。地址只取这张卡的 IPv4／IPv6 配置；未连接到这个网络时显示不可用，不借用另一张卡的数据。

## 刷新与移除

扫描保留旧结果，依据 `LastScan` 变化结束扫描提示；20 秒未完成显示超时，允许重新扫描。系统关掉 Wi-Fi 后取消未完成的加入与扫描显示。网卡拔出或 NetworkManager 重启时关闭所属确认／密码弹层，清除本次输入，返回网卡列表并提示。请求携带服务实例身份，排队期间或目标校验期间服务重启，旧请求在写入前终止。

配置保存使用原始 D-Bus Variant 设置拷贝，仅更新目标字段；支持 `VersionId` 的系统通过 `Update2(version-id)` 拒绝并发覆盖。旧系统没有此属性时，仍检查完整非密钥设置快照；仅凭据的外部并发修改无法在旧系统上获得相同保护。

## 验收

检查中英、两套主题、1280×720／960×600 的网络菜单、密码校验与显示、遗忘确认、进度、失败重试和详情，并运行原有 Wi-Fi 回归。安全实机探针仅使用明确指定的闲置卡和临时配置，保护 SSH 路由、现有配置与终端会话。真实加入、重新加入、主动断开、USB 物理拔插及设备现场按键操作单独记录，不能用 Mock 或离屏截图替代。

本次不增加隐藏网络手动加入、企业认证、热点、VPN 或静态 IP 编辑，不迁移既有网络配置。
