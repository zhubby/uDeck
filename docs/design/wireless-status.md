# 顶部无线状态图标

启动器顶部用图标展示无线状态，不再常驻显示网卡数量与连接数量。设置入口与 Wi-Fi 菜单保留完整文字摘要。

- 一张 Wi-Fi 网卡对应一个 32×32 图标，按内置、USB、其他网卡排序，同类按接口名与设备标识固定排序。两个图标间隔 12px，蓝牙与 Wi-Fi 组之间间隔 16px。信号变化、连接进度和刷新不会按强弱重排。
- 网卡作为热点时原位置显示天线广播图标，开启使用强调色，启动／关闭／恢复期间增加省略点，失败使用错误色及感叹号。热点没有接收信号格数；恢复客户端连接后重新显示实际信号。提示包含网卡、热点名称与状态，热点不计入 Wi-Fi 客户端连接数量。
- 信号使用圆点和三道弧线表示四格。0% 为零格，1–25% 为一格，26–50% 为两格，51–75% 为三格，76–100% 为四格。已点亮部分使用主题正文色，其余使用语义色 `signalInactive`，在两套主题背景上的对比度均不低于 3:1。
- 仅显示该网卡实际连接的 `ActiveAccessPoint` 的强度。扫描列表中同名或信号更强的热点不能代替当前连接；活动热点未出现在扫描列表时仍单独读取。未获取到强度时显示 `?`，不把未知值当作零格或满格。
- 未连接使用叉号，连接中使用强调色省略点，关闭使用斜线，未受系统管理使用短横线，暂不可用或读取失败使用感叹号。断开、关闭、连接中及异常状态清空信号格数，不沿用旧值。
- 无网卡时保留一个不可用 Wi-Fi 图标；它不代表虚构的网卡，说明文字显示“未检测到无线网卡”或实际服务错误。
- 蓝牙服务可用且已开启时显示蓝牙图标；关闭或不可用时隐藏。保持现有的连接与配对流程。
- 图标提供中英文可访问名称和悬停提示，包含网卡名称、接口、连接状态、网络名及信号百分比。用户网络名按纯文本显示，长文本在窗口内换行。提示被动读取现有鼠标拦截层的位置，保留壳内鼠标与按键导航规则。
- 图形使用统一圆头描边的矢量路径，按屏幕物理像素尺寸栅格化；复用现有字体和主题，不添加运行时依赖。与 Kenney 按键提示分工：无线图标表示系统状态，Kenney 素材表示输入按键。
- 执行任务时，进度文字与无线图标同时显示；文字根据剩余空间省略，不能遮挡网卡、蓝牙、电量和时间。

检查范围包括中英文、经典／黑暗主题、1280×720／960×600，以及 1×／1.5×／2× 像素比。自动化验证须分别记录模拟状态与真实设备状态，不将模拟双连接作为双网卡真实联网验收。
