这份记录跟踪返回延迟、首帧、会话恢复和发行验证。

崩溃与包生命周期验证使用独立进程和 Debian 容器。

焦点改变、服务重启和关闭会废弃旧查询。

按 B 返回跳过后台应用库视图重建。
输入路由纳入最终 ARM64 全量门禁。
会话监督器回归：6 项通过。
首次检查时，设备 1.0.2 的桌面、输入和快捷键健康。
候选没有安装到设备。
本机 evdev close 中位耗时约 23.9ms。
该测量不解释完整 B 返回路径的延迟。

`returnToHome` 诊断采样仅软件阶段。
尚未完成候选在 CM4 上的 B 返回对照。
软件诊断不等于机身按键或光学响应验收。

## 会话恢复

桌面重启预算统计最近 60 秒内的崩溃。
60 秒稳定运行后重置三次预算。
正常退出与会话 TERM 不重启桌面。
终止后恢复会话输入配置。

隔离进程测试覆盖正常退出、崩溃后恢复、预算耗尽和 TERM 清理。
测试不终止正式设备进程。
macOS 进程组存活探测可能返回 EPERM。
监督器保留清理流程，并发送 SIGKILL。
对应回归包含权限受限的进程组探测。

## CI 与构建身份

push/PR 执行版本门禁、Ruff 和逐文件隔离测试。
日常工作流不构建 deb。
发行包工作流仅响应已发布 Release。
发行包冻结 Git 提交、dirty 状态和源码摘要。
运行时诊断读取包内身份，不执行 Git。

Release 工作流下载上一版，再于独占 Debian 容器运行升级回退探针。
上一版本选择遍历全部 API 页，按稳定版本数值排序。
下载要求精确 arm64 deb 和已上传的校验清单。
首版没有上一包时执行干净安装。
进入 Debian 子进程前删除两个外层身份变量。
其他变量和父环境保留，避免临时仓库测试误用宿主身份。
发布边界回归 28 项通过。
最终 Debian 13 arm64、Qt 6.8.2 全量门禁通过。
共 2009 项通过，7 项跳过，0 失败。
跳过项均为依赖 rclone 的存档云同步集成测试。
Ruff、版本、依赖锁与 diff 检查通过。
