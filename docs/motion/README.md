# 动效与响应

动效只表达状态变化，不延迟输入、启动、存档或退出。
连续输入从当前画面改向，不等待上一段动画结束。
桌面与内置应用复用短过渡组件。

## 视觉约束

| 场景 | 行为 |
| --- | --- |
| 页面切换 | 内容保持不透明，单层位移不超过 6 px，120 ms 收束 |
| 焦点与视口 | 90 ms OutCubic，12 px 安全区，立即改向 |
| Console 补位 | 140 ms，焦点与点击区域跟随实际行位置 |
| 弹窗 | 打开 150 ms、关闭 110 ms、尺寸变化 120 ms |
| 弹窗中途关闭 | 同步停止尺寸动画，从当前几何淡出 |
| 启动等待 | 按请求身份保留退出文案，前台交接立即隐藏 |
| 封面 | 异步双缓冲，以条目身份和代次拒绝旧图片 |
| 长标题 | 等待 1200 ms，以 36 px/s 阅读，末尾停留 1400 ms，再返回停止 |

标题阅读完成后，关闭菜单和恢复前台不重播。
重新选择条目后允许重播；中断后重新等待。
关闭期间保留退出画面，但禁用旧按钮并拦截点击。
指标刷新不重播弹窗动画，不改变滚动与焦点。
设置行使用稳定 ID，值更新不重建代理。
Files 隐藏时延后布局，任务栏不改变卡片尺寸。

`UDECK_REDUCED_MOTION=1` 直接采用目标状态。
动画结束、页面隐藏或窗口退出后停止刷新。
圆点指针也遵循有限动画，详见[输入规范](../udeck/input.md)。

## 响应与负载

导航只发布选择索引，不序列化完整目录或系统清单。
主页、应用和设置复用未变化的模型。
后台索引、封面与网络任务携带请求代次，取消后不重启旧请求。
同一代应用授权查询只保留一个在途 D-Bus 请求。
Console 只在页面可见时采样，隐藏后丢弃迟到结果。
输入设备扫描先读 sysfs，减少无关 evdev 接口的开关。

交互音效复用一条 PCM 输出流，空闲时暂停。
导航限频、前后台取消和设备变化恢复见[音效规范](../design/interface-sounds.md)。
共享关闭时停止网络发现和无用途的轮询。
不以减少音效或关闭动效替代阻塞路径修复。

## 会话与验证

监督器统计最近 60 秒的桌面崩溃，使用三次重启预算。
稳定运行 60 秒后重置预算。
正常退出与会话 TERM 不重启桌面，结束时恢复输入配置。
实现边界见[架构](../udeck/architecture.md)。

Qt 探针覆盖连续改向、弹窗中途关闭、封面切换和减少动画。
测量前等待视口和内容几何就绪，记录全部输入及实际呈现分母。
首帧、活动帧间隔、事件循环延迟和物理响应分别测量。
离屏对照不表示目标 CM4 性能提升，也不替代物理按键验收。
工具入口及证据要求见[开发](../udeck/development.md)和[验证规范](../udeck/validation.md)。
