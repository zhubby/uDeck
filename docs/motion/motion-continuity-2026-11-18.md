# 连续输入与动效过渡

本轮采用利落、连续的短过渡。
输入立即生效，后续输入从当前画面改向。
本轮未提交 Git，未安装正式桌面。
2026-11-19 的正式替换见 [部署记录](motion-deployment-2026-11-19.md)。

## 实现

| 场景 | 行为 |
| --- | --- |
| 切页 | 内容保持不透明，单层位移不超过 6 px，120 ms 收束。 |
| 焦点与视口 | 90 ms OutCubic，12 px 安全区，连续输入立即改向。 |
| Console | 140 ms 补位，焦点和点击区域跟随实际行位置。 |
| Files | 普通导航不强制布局，隐藏布局延后，任务栏不改变卡片尺寸。 |
| 弹窗 | 打开 150 ms、关闭 110 ms、内容尺寸变化 120 ms。 |
| 弹窗中途关闭 | 停止尺寸变化，保留当前几何再淡出，重新打开采用新尺寸。 |
| 加载 | 按请求身份保留退出文案，前台交接立即隐藏。 |
| 封面 | 异步双缓冲，按条目身份与请求代次拒绝过期图片。 |
| 长标题 | 等待 1200 ms，以 36 px/s 阅读，末尾停留 1400 ms，平滑返回后停止。 |
| 减少动画 | 立即采用目标状态，停止正在进行的过渡。 |

标题完成后，菜单关闭和前台恢复不会重播。
重新选中条目后可以重播。
未完成的阅读被中断后，重新等待 1200 ms。

Settings 使用稳定 ID 模型。
行值刷新不再重建代理或改变滚动位置。
封面 URL 比较使用 Qt 规范形式。
含空格和中文的本地路径纳入回归。

原生 Wayland 复测发现延迟取消的问题。
改向后旧滚动从 173.56 px 继续到 186.63 px。
关闭后面板从 471.22 px 继续到 500.85 px。
选择变化和关闭现在同步停止旧动画。
新目标的布局计算仍使用下一事件轮。
两个主题的六项问题场景复测全部通过。
