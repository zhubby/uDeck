# uConsole 硬件概览

整理时间：2026-11-05。本文是阅读原始资料的导航，不是实机测试报告，也不是对任一批次硬件的验收结论。

## 1. 它是什么

uConsole 是 ClockworkPi 的模块化 Linux 掌上终端。理解它的关键不是把它看作一块固定配置的开发板，而是分开看 **核心板、载板、电源、输入、显示和扩展**。

```text
计算核心 CM4 / A06 / R01
        │ 核心接口；CM4 需要转接板
ClockworkPi v3.14 主板 / revision 5
        ├── MIPI 显示屏及背光
        ├── USB 键盘 MCU、轨迹球和游戏按键
        ├── USB、Micro-HDMI、音频、MicroSD 等接口
        ├── GPIO FPC 与扩展模块连接器
        └── 电池、电源管理和整机供电
```

来源：[官方产品说明的离线副本](../../references/uconsole/wiki-offline/clockworkpi-uconsole.md)、[装配手册](../../references/uconsole/clockworkpi-uConsole/Clockwork_uConsole_Assembly_Guidelines.pdf)、[主板 revision 5 原理图](../../references/uconsole/clockworkpi-uConsole/clockwork_Mainboard_V3.14_V5_Schematic.pdf)。示意图只表达功能关系，不替代电气连接图。

## 2. 计算核心与版本

| 核心 | 相关资料 | 阅读时的注意点 |
| --- | --- | --- |
| Raspberry Pi CM4 | CM4 官方数据手册、官方 CM4 转接板原理图、CM4 内核构建说明 | 核心上的接口能力不等于整机全部引出；尤其要对照转接板与载板 |
| A06 | A06 核心原理图、A06 镜像制作教程及补丁 | 属于不同 SoC 平台，不能直接套用 CM4 的设备树、镜像及 GPIO 编号 |
| R01 | R01 核心原理图、Allwinner D1 数据手册、R01 补丁 | 属于 RISC-V 平台，不可混用 ARM 镜像和二进制程序 |
| Raspberry Pi CM5 | CM5 官方数据手册、CM5 IO 板手册、uConsole CM5 overlay | 作为升级研究资料单独收集；需要核实转接板、电源、散热、设备树与实际外设兼容性 |

官方产品介绍还列有 A04，但本次归档的 uConsole 仓库没有给出与 CM4/A06/R01 同等完整的 A04 专用资料，因此不把它作为已整理完整的目标配置。

**两个容易混淆的版本号：**

- `v3.14 revision 5` / 原理图文件中的 `V5` 指 ClockworkPi 主板修订，不是 Raspberry Pi CM5。
- 2026-04-14 的官方镜像构建说明已经包含 `[pi5]` 与 `clockworkpi-uconsole-cm5` 配置，但这不证明任意 CM4 转接板可以无条件替换为 CM5。

来源：[CM4 数据手册](../../references/uconsole/raspberry-pi/cm4-datasheet.pdf)、[CM5 数据手册](../../references/uconsole/raspberry-pi/cm5-datasheet.pdf)、[当前官方镜像构建说明](../../references/uconsole/clockworkpi-uConsole/Code/patch/cm4/20260414/README.md)、[A06 原理图](../../references/uconsole/clockworkpi-uConsole/clockwork_DevTerm_A06_Core_for_Mainboard_V3.14_Schematic.pdf)、[R01 原理图](../../references/uconsole/clockworkpi-uConsole/clockwork_DevTerm_R01_Core_for_Mainboard_V3.14_Schematic.pdf)。

## 3. 载板和扩展接口

官方产品说明介绍的载板尺寸为 **95 × 77 mm**，采用模块化核心接口，并提供 USB、显示、音频和扩展连接。这里最值得先看的是主板两版原理图、CM4 转接板图，以及 4G 扩展图。

- **200-pin DDR2 SODIMM 形态接口用于连接计算核心。** 不要按普通内存插槽理解其用途。
- **52-pin Mini PCI-E 形态接口用于 EXT 模块。** 机械形态不等于标准 PCIe 外设兼容；接第三方模块前必须逐针核对供电与信号。
- **40-pin GPIO 采用 0.5 mm FPC。** 不应把它直接当成常见树莓派 2.54 mm 排针接口。
- 显示连接器同样有 40-pin 接口描述，不能和 GPIO FPC 混为一谈。
- 引脚功能必须联合核对“核心数据手册 → 转接板 → 主板 → 设备树”；本文没有生成未经实测的可直接接线 pinout 表。

来源：[官方产品说明](../../references/uconsole/wiki-offline/clockworkpi-uconsole.md)、[主板原理图](../../references/uconsole/clockworkpi-uConsole/clockwork_Mainboard_V3.14_Schematic.pdf)、[CM4 转接板原理图](../../references/uconsole/clockworkpi-uConsole/clockwork_Adapter_CM4_Schematic.pdf)、[4G 原理图](../../references/uconsole/clockworkpi-uConsole/clockwork_UC_4G_Schematic.pdf)。

## 4. 键盘、轨迹球与固件

键盘是独立 MCU 子系统，不只是被动按键矩阵。官方键盘图纸标注了 `GD32F103Rx`；仓库提供 Arduino/STM32 生态下的键盘源码，以及矩阵、键位、消抖、轨迹球、背光与 USB 相关实现。

- [键盘原理图，第 2 页](../../references/uconsole/clockworkpi-uConsole/keyboard_220816.pdf)：MCU、矩阵、UART、USB、轨迹球及背光连接。
- [键盘源码与编译说明](../../references/uconsole/clockworkpi-uConsole/Code/uconsole_keyboard/README.md)：固件入口、构建环境与配置。
- [离线 UART 刷写说明](../../references/uconsole/wiki-offline/How-to-use-keyboard-UART-port-to-flash-firmware.md)：正文已归档；3 张 GitHub 接线附件下载失败，保留原图链接，原理图 PDF 另已在本地。
- [刷写工具特别说明](../../references/uconsole/clockworkpi-uConsole/Bin/uconsole_keyboard_flash.tar.gz.readme_first.md)：不同固件格式与不同刷写入口不能想当然地互换。

没有在本机或设备上执行刷写、进入 DFU 或修改固件。原文中的旧版工具链和第三方编译说明也没有被重新构建验证。

## 5. 屏幕与 Linux 显示链路

官方介绍的是 5 英寸、1280 × 720 屏幕。资料库同时收集了 **JD9365DA-H3 数据手册、用户指南、主板图纸和内核 overlay**，用于把屏幕控制、MIPI 连接、背光与 Linux 配置串起来。

修改分辨率、旋转、背光或替换面板时，不应只改桌面显示设置；需要联合检查 panel 驱动、设备树时序、GPIO 与硬件连接。这里只归档相关实现，不代表任一替代屏幕已兼容。

来源：[产品介绍](../../references/uconsole/wiki-offline/clockworkpi-uconsole.md)、[显示驱动 IC 数据手册](../../references/uconsole/clockworkpi-uConsole/JD9365DA-H3_DS_V0.01_20200819.pdf)、[显示驱动 IC 用户指南](../../references/uconsole/clockworkpi-uConsole/JD9365DA-H3_User_Guide_Preliminary_V0.00_20200827.pdf)、[内核节选](../../references/uconsole/kernel/)。

## 6. 供电、电池与 4G

官方产品页介绍了 18650 电池模块及 USB-C 充电接口，并建议关机后更换电池。研究功耗或更换计算核心时，先看电源管理与电源轨，再考虑散热和实际负载；不能用核心的标称功耗代替整机供电验证。

4G 是独立扩展模块，不是所有 uConsole 都自带的功能。归档包括模块原理图、机械尺寸图、SIM7500/SIM7600 AT 命令手册、升级/降级说明，以及官方仓库里的两份 4G 固件包。收集文件不代表已经验证当地网络、SIM 卡、频段、语音或短信可用。

来源：[电池产品说明](../../references/uconsole/wiki-offline/clockworkpi-uconsole.md)、[装配手册](../../references/uconsole/clockworkpi-uConsole/Clockwork_uConsole_Assembly_Guidelines.pdf)、[4G 使用说明](../../references/uconsole/wiki-offline/How-to-use-the-4G-extension.md)、[4G 尺寸图](../../references/uconsole/clockworkpi-uConsole/clockwork_UC_4G_drawing.pdf)。

## 7. 软件与系统构建

本次抓取的官方 README 中，较新的 CM4 镜像条目是 **2026-04-14 的 `uConsole_CM4_v3.1_64bit.img.bz2`**，表中列出 Linux `6.12.62`。对应构建说明指定内核仓库 `cuu/ClockworkPi-linux`、分支 `rpi-6.12.y`、提交 `03436f4117533693d608b10eb4b3965987230b68`。

这次下载了官方 uConsole 仓库全部文件、Wiki 和指定提交的相关内核节选；没有镜像整个 Linux 内核仓库，也没有下载数 GB 的完整系统镜像。旧版镜像制作教程仍保留，但应按教程对应版本阅读，不可假定命令适用于新的镜像。

## 8. 结构设计与下一步阅读顺序

官方模型商品页提供 OBJ/STEP 模型领取说明，页面给出优惠码 `UC`。本次没有登录、提交订单或提供个人信息；另行归档了社区 `57Bravo/uConsole_3D_Models` 的 CAD 文件、README 和模型预览，没有下载该社区仓库中的全部实物照片。

**社区作者明确说明这些是粗略的 FreeCAD 模型，不适合严格公差，并建议后续使用官方发布的模型。** 因此它们只能用于初步布局和改装草图，不能当作官方模型镜像、生产图纸或已核验的加工尺寸。官方 OBJ/STEP 原件仍需通过商店正常领取。

推荐阅读顺序：

1. 装配手册：识别所有模块、紧固件、线缆、天线与装配关系。
2. 主板 revision 5 原理图 + CM4 转接板图：理解供电、USB、显示与核心接口。
3. 键盘原理图 + `Code/uconsole_keyboard/`：理解输入子系统和可修改边界。
4. 屏幕 IC 文档 + 内核设备树/驱动：理解显示和背光的软硬件交界。
5. PCB/Gerber、社区结构模型与 4G drawing：进入结构布局和扩展设计。
6. 按实际核心选择 CM4/A06/R01 构建资料；CM5 升级研究单列，不混用版本。

尚未拿到实际设备的核心型号、主板修订、扩展模块和系统版本，因此以上是通用资料整理，不是针对你那台设备的接线或刷机方案。
