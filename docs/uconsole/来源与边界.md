## 校验代表什么

本地校验包含文件大小和 SHA-256；官方仓库快照与选定社区/内核文件还核对 Git blob 标识；PDF 检查可解析性和页数；支持的压缩包检查目录或内容完整性。结果见 [validation.json](../../references/uconsole/validation.json)。

SHA-256 用于发现本地文件变化，Git blob 核对用于证明与所选提交的一致性。它们**不等同于作者签名验证、供应链安全审计、固件安全保证、PCB 制造验收或实机兼容性测试**。
