# Wi-Fi 加入与已保存网络管理交付记录

日期：2026-11-07。主程序 **0.1.16**，应用与终端继续为 **0.1.4**。沿用主题、字体和 Kenney 按键提示，没有新增依赖或迁移网络配置。交互规范见 [Wi-Fi 管理设计](../design/wifi-management.md)。

## 使用

「设置或 Y 快捷设置 → Wi-Fi → 选择网卡 → 选择网络 → A」打开操作菜单；同名多配置先选择具体 UUID。已保存网络在不在范围内或全部 Wi-Fi 关闭时仍可管理。

- 加入、重新加入和断开始终绑定所选网卡；另一张卡继续由系统管理。
- 遗忘默认取消，确认后精确断开活动配置并等待实际完成，再删除这份配置和凭据。同名其他配置保留；断开失败不删除，删除失败明确显示部分完成。
- 修改密码默认隐藏，X／F10 显示或隐藏本次输入；本地校验失败保留输入。保存后不主动重连，提示下次加入时使用；已有密码不读取或回填到界面。
- 自动连接开关只保存所选配置，关闭不会立即断开。保存失败重新读取实际状态。
- 正在加入显示系统阶段并提供取消；失败区分凭据、协商、地址获取、网络不在范围和其他系统原因，支持重试及重新输入密码。
- 详情显示 SSID、网卡、状态、安全、信号、IP、网关、DNS 和所选配置身份；地址只取所属网卡。

B 逐层返回并保留焦点；B 不取消已提交的加入。扫描依据 `LastScan` 完成，20 秒超时允许重试；加入 90 秒只提示等待超时，继续观察系统状态。取消使用操作 ID 和实际活动连接路径，不影响后来的连接。

## 审查与修复

在主线程依次按正确性、对抗场景和测试覆盖检查全部修改。可复现问题先补回归测试，再修复：

1. 取消早于激活返回时又变成正在连接：保留操作身份，返回后只撤销原活动连接；撤销失败继续显示实际进度并允许重试。
2. 遗忘在断开请求返回后立即删除、可能断开替换连接：精确撤销所选活动连接，等待实际结束，再核对配置并删除。
3. 仅密码的外部变更未进入快照：读取稳定的 `VersionId`，并用 `Update2(version-id)` 拒绝并发覆盖；系统密码请求也在提交后重新校验。
4. 后台进度替换明确选择的同名配置、删除后转向另一配置：管理操作始终保持 UUID，删除后不自动替换目标。
5. 高级兼容配置在关闭 Wi-Fi 后消失：保留可见说明，无法确认时禁用相关操作。
6. 扫描超时丢失旧结果、读取失败导致扫描不结束：保留稳定网络身份，并在失败路径继续推进超时。
7. 从保存入口打开详情时没有扫描信号：按原始 SSID 和安全类型关联当前扫描网络。
8. Mock 接受旧取消请求并断开当前连接：核对操作 ID，准备阶段保留原连接。
9. NetworkManager 重启后旧配置修改继续执行：UI 提交、后端队列和写入前均校验服务实例身份。

修复后的自动化检查没有遗留可复现问题。NetworkManager 低于支持 `VersionId` 的版本时，仅非密钥设置快照可用于外部修改检查，不能提供相同的仅凭据并发保护；本次设备版本为 **1.52.1**。

## 实机范围

设备有两张真实无线网卡。SSH 当前由 `wlan1` 承载；安全探针显式指定闲置 `wlan0`，拒绝选择承载 SSH 的接口。只更新基础包并重启 `udeck-fullscreen.service`。

通过临时配置验证自动连接的保存和关闭、原测试密码保留、新密码保存但不重连、外部修改后的旧请求被拒绝、精确遗忘和清理测试配置；扫描由 `LastScan` 实际增加确认。测试前后既有配置、活动连接及路由一致。

SSH 普通用户上下文的新增配置请求被系统权限策略拒绝，因此临时配置探针通过管理员权限执行。它只读取自己新建配置的测试凭据，不读取用户已有密码；这项结果不替代图形会话中的认证交互验收。可复用探针为 [`tests/wifi_management_device_probe.py`](../../tests/wifi_management_device_probe.py)。

安装后核对 73 个基础包文件、主程序与应用／终端版本、设置文件字节、6 份既有 NetworkManager 配置、终端进程 `381833` 及命令身份、默认音频输入／输出、SSH 路由。屏幕安装前处于 `DSI-1 off`，保持熄屏；启动器服务为 active。没有以服务存活或空 journal 代替真实渲染检查。

**未执行的现场项目**：真实网络加入／重新加入／主动断开、遗忘用户正在使用的活动配置、USB 物理插拔、NetworkManager 真实服务重启、现场实体按键与认证提示。承载 SSH 的连接没有进行上述破坏连接的操作；需备用通路或现场条件后单独验收。离屏截图和模拟测试只证明相应界面逻辑。
