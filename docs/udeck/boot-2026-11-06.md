# 0.1.1 全屏与开机默认会话配置记录

日期：2026-11-06，Asia/Shanghai。设备为现有 CM4 / Debian 13 / labwc uConsole。本次依用户要求将下一次图形登录配置为自动进入全屏 uDeck，不刷镜像、不卸载原桌面。

## 当前状态与生效边界

- 已安装 `udeck 0.1.1 arm64`，当前运行真实后端的全屏壳，不是 mock 或窗口化预览。
- DSI-1 整屏截图为 1280×720，无原版桌面面板、窗口标题栏或边框；foreign-toplevel 状态同时确认 uDeck 为 active / fullscreen。
- `home`、`switcher`、`quick-settings` 和再次 `home` 后均保持全屏。修复了 `show()` 在返回桌面时将窗口降回普通模式的问题；`--windowed` 预览保持普通窗口。
- 当前仍是原有 `rpd-labwc` 登录会话，通过临时用户服务 `udeck-fullscreen.service` 展示全屏壳。没有结束原桌面进程，也没有把这个临时服务设为开机服务。
- 下一次启动或图形登录由 LightDM 直接选择独立 uDeck 会话。该会话使用隔离的 labwc 配置与空 autostart，不启动原版面板和桌面管理器；原桌面入口仍保留用于回退。
- **没有自动注销、重启 LightDM 或重启设备。真正的独立登录和冷启动尚未验证。** 更改默认会话不等同于已经完成重启验收。

## 已生效的默认登录配置

显式运行的管理工具：

```sh
sudo python3 tools/configure-login.py --user zhubby
```

`sudo lightdm --show-config` 读取的有效配置包括：

```ini
[Seat:*]
user-session=udeck
autologin-user=zhubby
autologin-session=udeck
autologin-user-timeout=0
```

工具保留其余设置与注释，先备份再原子替换 `/etc/lightdm/lightdm.conf`，重复执行不额外修改。自动登录意味着接触设备的人可以直接进入此用户桌面，不提供开机身份验证。

## 回退与卸载顺序

先恢复本次备份并核对有效配置：

```sh
sudo cp -p /var/backups/udeck/lightdm-before-udeck-9462757189ed4b3c80bfd6e360767708.conf /etc/lightdm/lightdm.conf
sudo lightdm --show-config
```

这不会结束当前会话。保存工作后，在现场注销或重启，进入原「Raspberry Pi Desktop on Wayland」。如需卸载 uDeck，应在恢复默认登录配置之后执行 `sudo apt-get remove udeck`，避免默认会话仍指向已删除的程序。不要删除原桌面配置、用户数据或附带执行 `autoremove`。
