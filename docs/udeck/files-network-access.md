# Files 网络访问

在 **文件 → 菜单 → 网络访问** 中设置共享目录、网络和开放时长，选择“开启网络访问”。浏览器打开面板显示的地址即可管理文件，无需访问码。默认共享当前用户的主目录 `~/`，可以改为其他现有目录。

## 网络与时长

- 可以多选由 NetworkManager 管理且已连接的 Wi-Fi、有线、热点和 VPN。服务仅监听所选连接的实际地址，端口为 `8787`；页面不提供远程修改共享配置的接口。
- Wi-Fi 选择绑定网卡的永久地址与 NetworkManager 连接 UUID。切换到其他 Wi-Fi 后关闭原来的监听与已有连接；回到已选连接后恢复。地址改变时更新访问地址。NetworkManager 元数据不可用时停止监听。
- **永久**是默认值。开启后保存独立配置、启用 systemd 用户服务与该用户的 linger，开机后自动恢复。网络尚未连接时显示“等待所选网络”，监听失败会显示实际错误。
- **1 小时 / 6 小时 / 12 小时**按单调时钟计时，到期关闭；退出或重启 uDeck、重启文件服务或设备后均关闭。
- 关闭网络访问会保存关闭状态并禁用用户服务。已失效的网络仍可在网络列表中取消选择。

## 网页操作

网页沿用 uDeck 的字体、Logo、文件图标及 Classic / Dark 配色，跟随设备语言和主题。默认网格，可切换列表；支持面包屑、当前目录搜索、排序、隐藏项和分页加载，兼容手机尺寸与键盘操作。

- 上传文件或文件夹，也可将多个文件、文件夹拖入当前目录。拖拽支持空目录。文件选择器对于空目录的支持取决于浏览器。
- 勾选文件后显示批量工具栏：下载、复制、移动、重命名、移入回收站。重命名仅用于单项。
- 单文件直接下载；文件夹或多项以流式 ZIP64 下载，文件内容不整体装入设备内存。下载进度由浏览器管理。
- 同名项目可以取消、保留两者或跳过。替换普通文件需要再次确认；文件夹不合并或覆盖。
- 上传显示实际字节与速度；复制、移动和回收任务显示处理状态、项目数、字节、错误与取消入口。取消不会发布未完成的上传或复制文件。
- 回收操作使用设备的 Freedesktop 回收站，可在本机 Files 中恢复。外部卷使用该卷的回收站；卷或权限不允许时保留原文件并报错。

## 目录边界与资源

网页只访问共享目录及其子目录。逐级使用目录描述符与 `O_NOFOLLOW` 打开路径，拒绝绝对路径、上级路径、符号链接和特殊文件；共享目录被移除或替换时关闭服务，需重新选择目录。上传先写入隐藏临时文件，完整校验后原子提交。服务关闭或网络撤销时取消任务并回收临时文件。

同时运行最多 2 个上传、2 个下载；上传会话最多 8 个，批量变更最多排队 16 项，保留 64 个任务记录。ZIP 使用有界队列，写请求要求同源与页面请求令牌，拒绝不匹配的 Host。服务以当前用户权限运行。

## 安装与开发

Debian 包包含 `udeck-network-files`、网页与字体资源、`python3-aiohttp` / `python3-pyside6.qtnetwork` 依赖及 `udeck-network-files.service`。安装默认关闭，由本机菜单启用；永久模式要求安装用户服务。关闭功能不会改动用户可能用于其他服务的 linger 设置。

开发时可运行隔离的本地预览：

```sh
python -m udeck.network_files.daemon --standalone-root /path/to/test-folder --port 18787
```

默认只监听 `127.0.0.1`。正式模式通过会话 D-Bus `io.github.zhubby.uDeck.NetworkFiles` 控制，网页不能控制服务启停。配置保存在 `$XDG_CONFIG_HOME/udeck/network-files.json`（默认 `~/.config/udeck/network-files.json`，权限 `0600`）。
