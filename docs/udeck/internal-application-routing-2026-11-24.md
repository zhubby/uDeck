# 全局内置应用路由

uDeck 的界面动作只启动和激活内置应用。
此边界覆盖文件、应用列表、终端入口、网页链接和窗口切换。

## 启动和文件

`app_routing.native_app_id` 只接受六个固定应用身份。
桌面启动控制器在创建请求或发送 D-Bus 前校验身份。
应用列表、分类和语言刷新过滤第三方应用。
旧分类没有内置应用时回到全部应用。

`DesktopCatalog` 保留元数据读取能力。
启动只执行当前解释器中的固定 uDeck 模块。
同名 `.desktop` 的 Exec、Terminal 和工作目录不能替换命令。
文件路径固定为绝对路径参数，不作为命令解析。
“在此打开终端”固定进入 uDeck Terminal。
终端返回桌面时要求 uDeck 桌面服务存在。
服务不可用时保留终端并显示说明，不回退最小化。

文件页按现有类型表使用预览或 Music、Video、Reader。
ZIP 和其他未支持格式展示详情，不调用系统处理器。
文件打开和索引等待详见 [Files 工作区](files-workspace-2026-11-08.md)。

## 网页和窗口

Browser 和 Reader 显式禁止未知 URL 协议的系统分发。
Browser 的地址、页面导航和新窗口均留在内置控制器。
mailto、tel、magnet 和自定义协议不能唤起系统应用。
Browser 和 Reader 拒绝网页上传和颜色选择的系统选择器。
Browser 显示内置限制说明。
网页确认框和认证框继续使用进程内 Qt Quick 对话框。

Alt-Tab 两个方向进入 uDeck Console。
窗口服务在发送激活请求前校验身份。
Console、应用菜单和异步焦点恢复再次校验目标。
第三方应用仍可显示运行诊断和退出入口。

## 受控引擎和系统组件

保留 Emulator 启动并监管的 RetroArch 游戏进程。
游戏菜单、暂停、存读档和退出继续由 uDeck 提供。
原生菜单和桌面 companion 关闭，避免出现另一套应用入口。
RetroArch 窗口需要监管证明后才接受激活。
Wayland 窗口协议不提供 PID，授权沿用唯一窗口和监管进程模型。

锁屏和系统授权组件保留。
后台索引、同步和媒体工具继续运行。
终端中用户显式输入的命令不属于界面应用路由。
此策略不限制操作系统中的任意进程执行。

交互式 `rclone config` 会自行启动系统浏览器。
当前配置入口只在 uDeck 内显示说明。
已有远程和云同步继续可用。

## 验证边界

本轮使用隔离进程回归和离屏 QML 验证。
浏览器测试注册测试协议接收器，检测系统分发而不启动真实应用。
源码验证、设备安装和物理按键验收分别记录。
本轮未安装到 uConsole，也未执行真实 RetroArch 验收。

最终按测试文件去重，39 个文件共 720 项通过、5 项跳过。
其中 1 项需要 Linux 会话总线，4 项需要原生终端插件。
覆盖文件、冷启动、转发、网页、Console 和快捷键界面。
网页真实点击、弹窗、子框架和重定向均无系统协议分发。
文件上传与颜色选择在默认选择器创建前被拒绝。
浏览器慢重载夹具验证页面就绪后的真实输入。
修改范围 Ruff、空白检查和独立审查通过。

本地汇总为 `artifacts/global-internal-validation-summary.json`。
早期失败及修复后的日志分别保留，汇总使用每个文件的最终结果。
