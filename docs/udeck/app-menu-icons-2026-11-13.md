# 子应用菜单图标统一（0.2.7）

0.2.6 的视频菜单在两次截图中使用了不同图标。实机受控复现确认：正常桌面设置了 `QT_QPA_PLATFORMTHEME=qt5ct`，Qt 使用 PiXtrix 图标主题；第二次截图的独立进程未继承该变量，Qt 使用 hicolor，四个菜单图标均回退到 uDeck 内置的色块线稿。两次使用的已安装生产源码一致。

按用户选择，子应用设置菜单固定使用第二次截图中的内置色块线稿。共享 `SettingsRow.qml` 请求 `udeck-app-menu:` 图标，`IconProvider` 直接使用已有绘制函数，不再根据桌面主题选择子应用设置图标。没有新增样式选项。
