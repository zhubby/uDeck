## 发现并修复的问题

### 共享根目录返回过期列表

Linux ARM64 容器的网页上传和断线恢复用例稳定失败：上传已经完成，页面确实重新请求目录，但服务端第一次刷新仍返回旧列表。

最小复现和新增回归表明：`SharedRoot.directory()` 对根目录使用 `os.dup(root_fd)`，复制出的 fd 仍共享同一打开目录描述。在 overlayfs 上，文件变化后的目录遍历会沿用旧快照；子目录每次独立打开，没有这个问题。

`8fdf47c` 改为相对已持有的根 fd 执行 `os.open(".", DIRECTORY, dir_fd=self.fd)`，每个请求使用独立目录流，保留 descriptor-relative 路径限制与根目录替换防护。创建、重命名和删除后的根目录 / 子目录回归，修复前为 1 failed / 1 passed；修复后 Linux 网络相关检查为 51 passed。修复后的 ARM64 完整构建为 **1481 passed、0 skipped、13 warnings，636.72 秒**。

### 实机暴露的探针夹具问题

CM4 上未修改的 `63c0bba` 基线完整运行结果为 **1472 passed、7 failed、13 warnings，1740.94 秒**。原始失败日志和 JUnit 保留，没有把容器结果当作这一轮实机通过。

- 四个主题矩阵用例超时。带时间标记的独立探针证明，真正的断言差异是 Emulator 后台核心扫描进度从 224 变为 196。探针扫描了设备现有的 242 个核心及默认 `~/Games`，快照并非只受主题切换影响；断言失败后的退出等待又触发 60 秒上限。现改为私有 ROM / 核心目录，并等隔离库存任务结束后再比较完整快照。保留原 60 秒上限、8 个窗口、36 张截图、字体 / 颜色 / 状态保持断言。
- 三个 Browser 指针矩阵用例在地址保持断言处失败。诊断确认，夹具只把控制器地址改成 `https://layout.invalid/pointer`，真实 WebEngine 仍在 `about:blank`，随后到达的标题 / 加载通知把控制器地址恢复。现从独立回环 HTTP 服务实际导航并等待页面就绪，继续检查移动不导航及缩放后指针不越界。四个组合的独立修复复验为 **4 passed**。
- 原生 Video 探针错误地要求 VideoOutput 使用软件渲染的 QML 字幕桥。现按 `controller.media.software` 区分：software 仍验证控制器字幕和 QQuickText；native 验证实际 sink 的字幕交付。有效视频帧、画面颜色、外部 SRT、seek、续播等断言保留。原生字幕可见性另外由收起控制栏后的真实合成器截图确认，不能仅由 sink 文本推出。

这三项由 `94b7bab` 修复，仅修改测试探针。首轮安装产品对应 `8fdf47c`；最终设备包另包含下述音频产品修复。

修复后的 CM4 主题 / 交互回归为 **72 passed，289.72 秒**，视频和等待服务回归另为 **2 passed，15.13 秒**。四个主题组合分别耗时 21.493、19.448、19.026、18.951 秒，均在原上限内。macOS 对三个改动探针对应的完整模块复验为 **87 passed，248.40 秒**；Ruff 和 `git diff --check` 通过。实机完整基线与后续专项是不同运行，没有将它们表述为一轮完整套件全部通过。

### 音频查询触发自身持续刷新

首轮已安装 Shell 的隔离 offscreen / software 测量，30 秒空闲占用单核 CPU **14.481%**。15 秒 cProfile 和组件计数显示 34 次音频刷新、170 次只读 `pactl` 查询，所有 QML 动画均已停止。每次查询创建 / 移除 PulseAudio client，而 `_watch_audio()` 对所有订阅事件刷新音频；一次刷新又发起五个查询，形成持续循环。

`c4c1602` 只对 `sink`、`source`、`card`、`server` 事件刷新，保留设备及默认设备变化，忽略与设备状态无关的 client、stream、module、sample 事件。仅为订阅子进程设置 `LC_ALL=C`，保证中文会话中事件分类稳定，不修改主进程语言环境。

新增回归在修复前为 11 次刷新、预期 4 次，修复后通过；同时核对订阅进程清理及 locale 隔离。音频相关检查 macOS **37 passed，16.04 秒**，CM4 **37 passed，36.07 秒**。同模式 CM4 候选 offscreen 测量降至 **2.831%**，首帧 2.528 秒、RSS 195.67 MiB；这些数据只代表隔离软件渲染。

最终 ARM64 Debian 完整构建为 **1482 passed、0 skipped、13 warnings，615.59 秒**，整体构建退出 0、耗时 695.71 秒，清单记录 `c4c1602`、`gitDirty=false`。13 条 pytest 警告均为 `dbus_next` 的 Python 弃用装饰器警告。
