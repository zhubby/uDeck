# 0.1.3 手柄交互与会话级鼠标屏蔽

日期：2026-11-06，Asia/Shanghai。用户明确选择「整个 uDeck 会话都屏蔽鼠标，包括第三方应用」，取代 0.1.2 的轨迹球点击操作。

## 操作规则

| 按键 | 行为 |
| --- | --- |
| 上下左右 | 移动当前焦点；网格按实际行列移动，边界不循环 |
| A / Enter | 确认、打开当前项目 |
| B / Esc | 返回、取消或逐层关闭弹层 |
| X / F10 | 当前焦点项目的上下文菜单 |
| Y / F1 | 快捷设置 |
| L / PageUp | 上一主页面，到主页停止 |
| R / PageDown | 下一主页面，到设置停止 |

L/R 使用此前已实按确认的内置鼠标 272/273 事件，仅解释按下沿，不依赖轨迹球位置；弹层打开时不切页，也不改变弹层下的选中项。切回页面、退出菜单和返回目录保留已有焦点恢复规则。所有文件、设置、菜单和确认操作统一通过方向键与 ABXY 执行。

不再使用指针选中项目、单击打开、双击文件、拖动或滚轮滚动。壳内光标隐藏；实体键盘继续输入文字，j/k/u/i 等普通字母不映射为 ABXY。文本编辑中的方向键仍用于移动文字光标。

## 会话范围

真实全屏壳使用独立的 `PointerGuard`，持有当前用户可访问的鼠标/触摸板事件接口，丢弃移动、滚轮与鼠标按键。第三方应用前台时继续持有鼠标，L/R 也不会在后台翻动 uDeck 页面；ABXY 的独立手柄接口仍在失焦时释放给应用。退出壳时释放鼠标接口。

不独占整个键盘。混有普通键盘键位的设备接口不强制抓取，权限失败、按键未松开和设备故障记录于 `udeckctl doctor --json` 的 `runningShell.input.pointer.errors`。热插拔扫描后接管新的独立鼠标；外接鼠标不会被当作内置 L/R 切页键。

独立 uDeck 会话的 labwc 配置额外按精确设备名 `ClockworkPI uConsole Mouse` 设置 `sendEventsMode=no`，从合成器启动时禁用内置指针事件。原桌面的 labwc 用户配置不变。窗口化或 mock 预览只在 uDeck 窗口内消费鼠标手势，不接管开发机鼠标；`--no-input` 可用于不抓取设备的诊断。

第三方应用依赖其自身的键盘或手柄支持，uDeck 不改写第三方界面的焦点系统、不注入虚拟 L/R，也不保证隐藏第三方自行绘制的光标。独立会话可使用 `Ctrl+Alt+Esc` 返回桌面。
