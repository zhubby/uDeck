# 中英文界面与验证记录

日期：2026-11-06（Asia/Shanghai）。基础包 0.1.6，uDeck Terminal 0.1.1。

## 使用

- 默认界面为英文，不随操作系统的 LANG 自动切换；旧配置中没有语言字段时也使用英文。
- `Settings → Language` 或 `Y → Language` 打开语言选择，方向键选择 `English` / `简体中文`，A 或 Enter 应用，B 或 Esc 返回。
- 切换立即生效，保留当前页面、选中项目、已打开的提示和密码输入。保存失败时保持原来的语言，并在当前界面显示错误。
- 偏好保存在 `~/.config/udeck/settings.json` 的 `preferences.language`，内部值为 `en` / `zh_CN`。未知值回退到 `en`。`--mock` 使用独立临时配置。
- Terminal 0.1.1 每秒读取该偏好，只更新界面，不重建会话。旧版已运行的终端需要正常关闭后再启动，升级不结束现有任务。
- SSID、文件名、设备名称、窗口标题、终端输出、搜索和粘贴内容保留原文。第三方应用列表使用 `.desktop` 自带的 Name / Comment 语言项及其默认项。

## 实现与维护

`src/udeck/i18n.py` 提供显式标记的延迟消息 `tr()` 和 `render()`。QML 通过控制器的 `translate()` 使用同一组词条。两份 UTF-8 JSON 词典位于 `src/udeck/locales/`；wheel 和 Debian 基础包都携带它们，不增加运行依赖。

为了保留原有服务状态、错误比较及现有中文代码文案，消息键沿用原文；默认展示语言仍是英文。只有显式标记的界面消息参与翻译。不要对完整快照中的任意字符串做字典替换，否则同名 SSID 或用户文件名会被误翻译。

添加文案时：

```python
from .i18n import tr

message = tr("连接 {name}？", name=network_name)
```

在 `en.json` 中加入 `"连接 {name}？": "Connect to {name}?"`，在 `zh_CN.json` 中加入中文值。使用命名参数，不在 f-string 中提前格式化消息；用户数据作为参数传入。现有短标签拼接也保留各部分的翻译标记。

后台的对象信号保留消息标记，并复制发布的服务状态以隔离工作线程和界面线程。语言变化只重绘显示，Wi-Fi 目标、弹层 token、配置 ID 和输入映射保持原标识。应用名重新排序时按应用 ID 恢复选中项；终端标签使用 dataChanged 更新，不重置会话模型。
