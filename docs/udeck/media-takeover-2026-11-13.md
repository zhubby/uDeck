# 音乐与视频播放抢占（0.2.9）

音乐与视频统一使用“后播放者抢占”规则。视频设置删除“视频结束后恢复音乐”，开始视频时也不再询问是否暂停音乐。旧状态文件里的 `resumeMusic` 偏好不再参与播放控制。

| 操作 | 结果 |
| --- | --- |
| 开始或恢复视频 | 音乐暂停，视频播放 |
| 开始或恢复音乐 | 视频暂停，音乐播放 |
| 仅激活应用窗口或打开菜单 | 当前播放者保持播放 |
| 暂停、播完或关闭当前播放者 | 另一方继续暂停 |

被抢占的一方保留进度与队列。共享播放控制器通过会话 D-Bus 的可替换服务名维护播放所有者；快速切换后仅保留最后一个播放请求，延迟的所有权通知会重新核对当前所有者。
