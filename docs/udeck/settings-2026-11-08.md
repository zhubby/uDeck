# 时区设置与键位测试交付记录

日期：2026-11-08。基础包 **0.1.17**，应用包与独立终端继续使用 **0.1.4**。交互设计见[系统设置规范](../design/system-settings.md)，按键反馈见[Input Prompts 规范](../design/input-prompts.md#键位测试中的反馈)。

## 使用

- 「设置 → 时区」或「Y 快捷设置 → 时区」：按区域、城市选择，A 应用并保存到系统；菜单保持打开，B 逐层返回且保留焦点。支持中英文，当前值跟随系统状态，顶部时钟立即更新。
- 「设置 → 键位测试」或快捷设置同名入口：查看方向键、ABXY、L/R、键盘输入与组合。按下时边框高亮并缩小，松开复原，已测试键位显示勾选；显示来源、最近输入、按住组合、次数及测试数量。
- 短按 B／Esc 测试此键，长按 **1.2 秒**返回。测试期间不触发确认、翻页或快捷菜单，不改写校准；普通字母仅显示键名。焦点丢失、弹层打断或设备断开后清除按住状态。

时区由 `org.freedesktop.timedate1` 管理，校验系统可选列表并读回实际结果，认证或保存失败时保留真实状态。默认时区由操作系统决定，不新增应用偏好副本，不修改时间、NTP 或 RTC。键位测试不保存输入记录。

## 审查与修复

在主线程按正确性和边界情况审查。以下问题均先复现并补回归，再修复：

1. 测试页失去前台焦点后仍可能记录内置肩键事件：焦点丢失时清除状态，后台事件不再进入诊断。
2. 临时弹层打断后可能漏掉松键，留下高亮或返回计时：插入弹层前清空按住状态并停止退出计时。
3. 960×600 下长后台消息可能撑出测试弹层：此页提示显示单行摘要；其他菜单保留详细提示，矩阵新增长消息场景。

同时验证等待保存期间禁用重复提交、失败后解除禁用并保留实际时区、不同输入来源同时按住一个动作时分别释放，以及普通 J/K/U/I 不成为 ABXY。

## 实机完成与待验收

已在 uConsole 安装 **0.1.17**，仅重启 `udeck-fullscreen.service`。运行中的启动器报告对应版本，首帧已产生，输入设备可读；这不替代实体屏幕和按键验收。

普通桌面用户通过实际 D-Bus 查询当前 **Asia/Shanghai** 和 **485 个**可选时区，与 `timedatectl` 独立读回一致。再次提交当前值时没有调用任何 `Set*` 方法，未改变真实时区。本次未执行切换到另一时区的操作，也未通过管理员命令替代图形认证。

安装前后核对基础包 77 个文件、设置文件字节、6 份网络配置、SSH 路由、默认音频输入／输出、时区／NTP／RTC 设置一致。既有终端进程 **381833** 及命令身份保留；屏幕原为 **DSI-1 off**，继续保持熄屏，启动器服务为 active。主工作区的其他未跟踪资料保留。

**待现场完成**：实体方向键／ABXY／L/R 的按压、松开、组合和长按退出，真实屏幕上的动画观感，以及从图形会话修改时区时的 Polkit 认证与跨时区保存／恢复。模拟输入、设备枚举、首帧和服务存活不算现场验收。
