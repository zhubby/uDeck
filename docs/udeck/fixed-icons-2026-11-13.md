# 全界面固定图标检查（0.2.8）

0.2.7 固定了子应用设置行的图标，但共用图标提供器仍对普通名称调用 `QIcon.fromTheme()`。导航栏、应用列表、窗口列表、启动提示和普通菜单因此仍可能随系统图标主题变化。

0.2.8 移除这一共用入口的系统主题查询：普通名称统一使用已有内置色块线稿；文件类型和系统设置继续读取随包 SVG；显式应用图片文件直接加载其固定路径。生产 Python、QML 和 Web 代码中已没有系统图标主题查询或 `icon.name` 图标入口。

## 检查范围

| 位置 | 固定来源 |
| --- | --- |
| 导航栏、普通菜单、应用与窗口列表、启动提示 | 共用图标提供器的内置绘制；原生应用标识使用随包首页 SVG |
| 全部六个子应用的设置菜单 | 共享设置行和已有内置色块线稿 |
| 系统设置和快捷设置 | 随包 settings-icons SVG |
| 文件列表和文件菜单 | 随包文件类型 SVG及内置绘制 |
| 首页、品牌、状态栏和按键提示 | 随包 SVG、PNG 或既有 QML 绘制 |
| Web 文件访问界面 | 服务端随包文件类型 SVG、品牌 SVG 和页面内 SVG |
