# 轨迹球相对移动与方向连续性

用户确认四倍位移改善了速度，但仍不跟手。
源码检查没有发现反向倍率或横纵轴交换。
旧链路存在两份光标位置和逐轴提交。
桌面圆点累加原始位移，应用累加绝对位置。
两条路径在切换窗口时没有同步。

## 输入链路

PointerGuard 保留原始诊断信号。
横纵位移按 SYN_REPORT 合并。
按钮边沿前先刷新已读位移，避免点击旧位置。
半帧跨读取保留；丢帧和设备断开时丢弃。
锁定、暂停或诊断状态变化时丢弃半帧。

TrackballInput 为桌面和应用提交相对移动。
优先保留内核单调时间；不支持时使用读取时间。
VirtualInput 一次提交双轴向量。
合成器维护全局光标位置和屏幕边界。
PointerCursor 从 Qt 鼠标事件读取圆点位置。
方向键指针模式使用同一相对入口。
进入该模式时不再跳到旧坐标。

四倍位移倍率、点击分类和圆点动画保留。
本轮没有调整轴向、固件或增加惯性。
