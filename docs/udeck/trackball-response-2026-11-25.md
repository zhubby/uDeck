# 轨迹球移动响应

用户反馈：桌面与应用内的光标均几乎不动。
原实现把机身轨迹球一个位移计数映射为一个像素。
桌面圆点与应用虚拟鼠标各自执行这条映射。
应用路径发送绝对坐标，绕过系统鼠标加速。
此前圆点改动只调整显示和按钮动画。

机身位移现在统一使用 4 px/count。
共用倍率位于 pointer.py。
桌面圆点和应用注入各自应用一次倍率。
原始诊断信号保留设备计数。
滚轮、普通鼠标和方向键保持原来的位移规则。
点击分类、长按时长与圆点动效保持原样。
不添加移动插值、惯性或持续刷新。

## 验证

修复前，桌面位移和两个应用位移回归失败。
连续八次单计数水平移动，应用只移动八像素。
修复后，同样输入移动三十二像素。
反向输入可回到起点，不积累偏差。
虚拟鼠标其他来源的一像素输入仍只移动一像素。
滚轮输出保持原值。
六个专项文件共 107 项通过、2 项环境跳过。
全源码 Ruff 和空白检查通过。

设备当前识别到 ClockworkPI uConsole Mouse。
会话安全检查、指针读取与虚拟输入均报告可用。
一次十八秒读取采样未捕获位移事件。
该采样不能判断物理传感器或实际滚动频率。
四倍倍率是针对明确软件瓶颈的初始调校。
实体滚动手感需用户复验。

原始证据位于 artifacts/trackball-response-20261125/。
