# uDeck 1.0.0 发布前验证

日期：2026-11-17。目标：uConsole CM4、arm64 Debian 13。

## 发行约定

- `src/udeck/__init__.py` 是唯一版本源，当前版本为 `1.0.0`。
- Debian changelog 使用 `1.0.0`，发布标签使用 `v1.0.0`。
- GitHub Actions 只监听 `release: published`。
- 工作流验证包后保存 `udeck-1.0.0-arm64` 制品，并上传相同的 Release 附件。
- 构建清单记录包内元数据、包哈希、源码提交和工作区状态。

构建与安装步骤见 [Debian 发行说明](debian-distribution.md)。

## 发布前修复

- 视频指针观测改用窗口坐标。页面过渡不再重置控件空闲计数。
- 音频和设置探针等待弹窗过渡结束，再执行原有边界断言。
- 首页回归使用当前的 Console 名称。

视频回归覆盖拖拽保持、释放后隐藏、离开播放和返回播放。
指针移动仍能唤醒控件，播放按钮仍能接收点击。

## 本地验证结果

在原生 arm64 Docker 容器中运行完整 Debian 构建。
本地仅将 Debian APT 主机替换为可达镜像，保留官方签名校验。
仓库中的 CI Dockerfile 保留官方 Debian 源。
