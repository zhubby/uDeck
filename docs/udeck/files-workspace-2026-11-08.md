# Files 工作区

## 功能与边界

文件页保留顶部四个页面和现有按键导航，不增加鼠标依赖，不更改系统默认应用、原桌面、Shell 或登录配置。Classic / Dark 与英文 / 简体中文均使用现有主题和字体。

- **浏览**：默认使用全宽图标网格，不显示左侧位置栏；1280×720 下为 5 列，960×600 下为 4 列。图标下方显示最多两行文件名，底部显示所选文件的大小、修改时间或回收站原路径。面包屑保留在顶部；用户目录、存在的 XDG 下载/文档/音乐/视频/图片目录、文件系统、回收站、设备和收藏通过 `X → 位置` 访问。收藏最多 64 项，排序、筛选和收藏写入现有设置文件。
- **搜索与组织**：只搜索当前目录的文件名，不递归索引子目录；名称采用自然排序，支持修改时间、大小及反向排序。音频、视频、图片、电子书、文本、压缩包及其他类型筛选保留文件夹，便于继续导航。
- **图标与选择**：类型图标、两行文件名、所选项目详情及链接标记；剪切项目降低透明度，多选在图标右上角显示勾选框。重命名和新建后按项目路径恢复焦点，而不是保留原来的网格序号。窗口尺寸变化时保持当前文件与勾选状态。
- **类型图标**：内置 65 类 Tabler 图标，覆盖常见 Office、文本、媒体、代码、安装包、字体、磁盘与游戏文件等，详见 [图标与来源说明](file-icons-2026-11-09.md)。SVG 随包离线分发，未知类型保留中性图标；图标识别不改变已有打开/预览能力。
- **刷新**：返回文件页、窗口重新激活、目录/当前所选文件变化时刷新，合并短时间内的变化事件；文件页另有 10 秒周期检查。打开弹层时延后刷新，刷新不改变网格/面包屑焦点。目录或设备消失时返回用户目录。
- **批量操作**：多选、全选、复制、剪切、粘贴、移入回收站、恢复。改变筛选或搜索时清除不可见的勾选，避免操作隐藏项目；多选为空时不会默认操作当前行。
- **后台任务**：显示扫描准备、字节数、文件数、当前路径、目标、速度和预计剩余时间。A 将任务转入后台，B 请求安全取消；可从文件菜单重新查看任务。后台错误只提示结果，不抢占当前页面或弹层，详细原因保留在任务中。
- **冲突处理**：默认取消，可保留两者或跳过同名项目；只对普通文件提供额外确认后的替换。文件夹永不合并或覆盖。安全无覆盖重命名防止预检查后的重名竞争。
- **预览与详情**：UTF-8 文本最多读取 64 KiB，按纯文本显示并标注截断；二进制内容不作为文本显示。图片文件最多 8 MiB、1200 万像素，缩放至最多 840×420，按窗口剩余空间显示。SVG 不渲染；不支持的格式和文件夹展示元数据；链接仅展示目标，不跟随预览。
- **打开方式**：使用已安装应用的 MIME 声明提供选择，系统默认选项通过 GIO 打开，不修改默认文件关联。后备启动使用参数数组及单次字段展开，不经过 Shell。
- **挂载设备**：识别 `/media`、`/run/media`、`/mnt` 下的挂载，在 `X → 位置` 显示只读或剩余空间；该菜单的“安全卸载”可选择设备并明确确认。卸载前复核挂载 ID、设备和路径；任务正在使用的设备不可卸载。先离开设备目录，再请求 GIO 正常卸载，不使用 sudo、强制卸载或授权绕过。
- **回收站**：读取符合 Freedesktop 结构且通过权限/身份检查的用户回收站和挂载卷回收站，展示原路径；可恢复原位置或选择已有目标目录，重名自动保留两者。不提供永久删除，也不将删除失败降级成永久删除。

### 取消、跨文件系统与恢复

取消会清理当前尚未提交的临时副本，已经完成的项目保留，不做可能删除用户文件的整批回滚。复制时检查源文件变化，链接不递归跟随，设备/套接字/管道不复制。同一文件系统移动使用原子重命名；跨文件系统移动先复制，再将源项目移入回收站。源项目回收失败时保留两份并报告原因，不永久删除源文件。

回收站恢复使用原子的无覆盖重命名。目标文件夹必须已存在且与回收站源位于**同一文件系统**；不自动创建缺失的父目录，不冒险执行跨卷的复制后删除。跨卷恢复请求会明确失败，回收站内容保持，用户可改选同卷的现有目录。

## 按键

| 按键 | 文件页行为 |
| --- | --- |
| 方向键上/下 | 按网格行移动；第一行向上进入面包屑，再向上进入顶栏 |
| 方向键左/右 | 在当前网格行内移动，边界停止；面包屑中逐级选择 |
| A / Enter | 打开文件/目录、进入所选位置；多选模式中切换勾选 |
| B / Esc | 返回上级/退出多选/关闭弹层；传输弹层中请求取消 |
| X / F10 | 文件操作、位置、设备、搜索、排序、筛选、收藏、任务详情 |
| Y / F1 | 原有快捷设置 |
| L/R / PageUp/PageDown | 原有主页面切换，不绕过弹层 |
| Ctrl+F / Ctrl+L | 搜索文件 / 前往绝对路径 |
| Ctrl+C / Ctrl+X / Ctrl+V | 复制 / 剪切 / 粘贴 |
| Ctrl+A / Space | 全选可见项目 / 切换当前项目勾选 |
| F2 / F5 / Delete | 重命名 / 刷新 / 确认移入回收站 |
| 预览中的方向键 | 按行或按较大幅度滚动文本 |
| 任务弹层中的 A / B | 转入后台 / 请求取消；完成项保留 |

普通字母仍用于文本输入，不作为隐式导航按钮。文本输入中的组合键由输入控件处理，不会触发文件操作。

## 模型与兼容性

文件列表使用 `QAbstractListModel`，初始暴露 200 行，按需每批增加 200 行；勾选和剪切状态通过模型角色更新。QML 使用 `viewSnapshotJson`，所有页面均不重复序列化文件数组，文件页也不重复传递 `items`。外部 `snapshotJson` 保留原 `files`、`items` 及现有 CLI / D-Bus 导航契约，并增加文件工作区状态；没有更改外部会话或输入协议。

目录读取和小操作沿用原工作队列，传输使用单独的单工作线程，后台传输时可继续浏览或启动应用。目录请求带有代次标识，过期扫描结果不覆盖更新的目录请求。任务完成只消费启动时对应的移动剪贴板，不清空后来重新设置的剪贴板。

## 本地复现与验收

使用项目兼容的 Python 3.11–3.13、PySide6 6.8 环境：

```sh
PYTHONPATH=src QT_QPA_PLATFORM=offscreen QT_QUICK_BACKEND=software QT_QUICK_CONTROLS_STYLE=Basic \
  python -m pytest -q tests/test_file_icons.py tests/test_files_features.py tests/test_files_locations_trash.py \
  tests/test_files_model_preview.py tests/test_files_jobs.py tests/test_files_controller.py \
  tests/test_files_qml.py tests/test_core.py tests/test_safety.py tests/test_ui.py tests/test_i18n.py \
  tests/test_sound_interactions.py

PYTHONPATH=src QT_QPA_PLATFORM=offscreen QT_QUICK_BACKEND=software \
  python tests/files_qml_probe.py /tmp/udeck-files-preview zh_CN dark 1280 720

PYTHONPATH=src QT_QPA_PLATFORM=offscreen QT_QUICK_BACKEND=software \
  python tests/file_icons_probe.py /tmp/udeck-file-icons-preview
```

QML 探针覆盖两种语言、两种主题、1280×720 / 960×600，输出文件页、多选、操作菜单、位置菜单、文字预览、图片预览及传输弹层截图；同时检查网格导航、缩放、末行可见性、快捷键、预览滚动复位、进度比例和弹层边界。探针中的传输数据是 **Mock**，不能作为真实文件传输或实机操作证据。真实临时文件操作另由核心和控制器测试覆盖。
