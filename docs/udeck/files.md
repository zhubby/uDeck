# Files 工作区

文件页默认以图标网格浏览主目录。
1280×720 显示五列，960×600 显示四列。
面包屑、类型图标、两行文件名和所选项详情组成工作区。
位置菜单提供 XDG 用户目录、文件系统、设备、收藏和回收站。
搜索只匹配当前目录文件名，不递归索引。
支持自然名称、时间、大小排序和类型筛选。

## 操作与任务

| 输入 | 动作 |
| --- | --- |
| 方向键、A/Enter、B/Esc | 选择、打开、返回上级或关闭弹层 |
| X/F10 | 位置、文件操作、排序、筛选、收藏和任务 |
| Ctrl+F / Ctrl+L | 搜索 / 前往绝对路径 |
| Ctrl+C / Ctrl+X / Ctrl+V | 复制 / 剪切 / 粘贴 |
| Ctrl+A / Space | 全选可见项 / 切换当前勾选 |
| F2 / F5 / Delete | 重命名 / 刷新 / 确认移入回收站 |
| 传输弹层 A / B | 转入后台 / 安全取消 |

文字输入期间，编辑快捷键交给输入控件。
筛选或搜索改变时清除不可见勾选，避免误操作隐藏文件。
焦点以路径恢复，不依赖旧行号。
目录和设备消失时回到用户目录。
后台任务报告文件数、字节数、速度、剩余时间和错误。
取消只清理尚未提交的副本，已经完成的项目保留。

## 内置打开与预览

文件确认和菜单打开共用 `apps/common/library.py` 格式表。
后缀不区分大小写，不调用系统 MIME 处理器。

| 类型 | 后缀 | 目标 |
| --- | --- | --- |
| 音乐 | MP3、FLAC、OGG、OPUS、M4A、AAC、WAV、AIFF | Music |
| 视频 | MP4、MKV、WEBM、MOV、AVI、M4V、TS | Video |
| 文档 | TXT、PDF、EPUB、MOBI | Reader |
| 其他文本和图片 | 受限预览支持的格式 | 预览与详情 |
| ZIP、目录、其他格式 | — | 元数据详情 |

TXT 的预览与详情仍可查看文本，并确认进入 Reader。
文件符号链接和回收站内容不启动应用。
应用冷启动与已有实例接收同一绝对路径参数。
未索引文件触发父目录扫描，连续请求只保留最新目标。
扫描失败或结束后无匹配会显示错误。
取消扫描同时撤销待打开请求。

文本预览最多读取 64 KiB，以纯文本显示并标明截断。
图片限制为 8 MiB 和 1200 万像素，缩放至最多 840×420。
SVG 和符号链接不渲染，类型图标不代表能打开该格式。
应用启动命令固定到 uDeck 模块，不执行桌面元数据中的命令。

## 冲突与数据保护

同名冲突默认取消，可保留两者或跳过。
替换普通文件需要额外确认，目录永不合并或覆盖。
同卷移动和回收站恢复使用无覆盖原子重命名。
跨卷移动先完整复制，再将源移入系统回收站。
回收失败或源发生变化时保留源，并报告部分结果。
不存在递归永久删除源的后备路径。

复制先写私有临时文件，验证完整性后发布。
链接不递归跟随，管道、设备和套接字不复制。
回收站按 Freedesktop 结构及权限、身份校验读取。
恢复目录须已存在且与回收站源同卷；跨卷恢复明确失败。
回收站不提供永久删除。

挂载设备按挂载 ID、设备和路径复核。
安全卸载前离开目标目录，正在传输的设备不能卸载。
卸载调用 GIO，不提权或强制卸载。

## 模型与服务边界

`QAbstractListModel` 初始暴露 200 行，按需每批增加 200 行。
QML 使用轻量视图快照和模型角色，不重复序列化完整文件数组。
目录请求携带代次，旧结果不能覆盖新请求。
传输使用独立的单工作线程，浏览与应用启动保持可用。
任务完成只消费启动时对应的剪贴板。
目录监听、重新激活和周期检查合并刷新，弹层期间延后更新。

网络共享由[网页文件访问](files-network-access.md)和[SMB](sharing.md)独立提供。
验证方法见[验证规范](validation.md)。
