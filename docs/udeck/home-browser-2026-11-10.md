# 首页 Browser 入口与横向滚动验证

首页按终端、音乐、视频、阅读器、模拟器、浏览器、设置的顺序提供七个固定入口。1280×720 和更宽窗口一屏完整显示六张卡片，卡片尺寸保持 180px；左右方向键逐项移动，滚动后选中框完整可见，边界不循环。窄窗口随选中项滚动。返回首页、上下切换标签、设置返回与语言切换均保留焦点。

Browser 使用现有 `io.github.zhubby.uDeck.Browser.desktop` 启动入口。未安装时保留禁用卡片，行为与其他原生应用一致。图标采用 [Bootstrap Icons 1.13.2 的 globe2](https://icons.getbootstrap.com/icons/globe2/)，MIT 许可；仅替换 `currentColor` 为现有暖金色。归档、原始文件和本地文件的散列及转换说明见 `src/udeck/assets/home-icons/manifest.json`。

## 验证

- 本地首页导航、启动路由、翻译、控制器和已有 QML 回归：90 项通过。补充选中框与隐藏卡片的边缘裁切断言后，最终 QML 渲染与按键回归 27 项通过。
- 首页渲染矩阵：1280×720、960×600、1920×1080 × 英文 Classic、中文 Classic、中文 Dark，共 9 组；检查首页与设置方向的六卡窗口、来回滚动、Browser 图标加载、设置返回和快捷设置焦点。实机 Qt 6.8.2 的独立离屏渲染也全部通过，54 张截图，QML 错误为空。
- 实机使用新版首页模型与真实应用目录，通过方向导航和确认操作启动 Browser；观察到原生 Wayland 窗口，Browser D-Bus 诊断的 QML 错误为空。验证后正常关闭本次启动的浏览器并恢复原窗口焦点。该检查验证入口与应用启动，不涉及网页联网功能。
- 七个 SVG 均与固定版本 npm 归档逐文件核对，颜色替换、SHA-256、字节数和许可一致。

本地测试、源归档、实机截图和部署清单保存在 `artifacts/home-browser/`。
