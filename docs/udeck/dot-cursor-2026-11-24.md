# 圆点鼠标与有限交互动画

uDeck 桌面、内置应用和 Terminal 共用圆点指针。
中心为 8 px 白色圆点，深色细边保证明暗背景可见。
外侧为 20 px 主题色细环。
鼠标位置直接跟随事件坐标，不插值或拖尾。
机身轨迹球保留原来的边界限制。

出现时淡入并轻微放大。
按下时圆点和细环收紧，松开时播放一次扩散环。
动画结束后停止刷新，不添加循环呼吸动画。
按住鼠标时暂停原来的三秒隐藏计时。
松开后重新计时，键盘导航和失焦立即撤销按下状态。
减少动画模式直接切换状态，不播放扩散环。

指针层不接收输入。
共享状态只观察所属窗口，避免遍历 WebEngine 私有对象。
内置应用保留原来的鼠标点击策略。
Terminal 在屏蔽鼠标输入前只转发视觉反馈。
Terminal 的文本插入光标和 PTY 输入不变。
原生错误弹窗出现前恢复系统指针。

已经运行的窗口保留已加载的 QML。
它们在正常重新打开后采用新样式。
